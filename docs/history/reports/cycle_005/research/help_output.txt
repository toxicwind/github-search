GitHub Advanced Search API & CLI

Usage: gh-search [OPTIONS] <COMMAND>

Commands:
  query  Execute a search query
  serve  Start the API server
  help   Print this message or the help of the given subcommand(s)

Options:
      --token <TOKEN>  GitHub Personal Access Token (or set GITHUB_TOKEN env) [env: GITHUB_TOKEN=]
  -v, --verbose        Verbose logging
  -h, --help           Print help
  -V, --version        Print version
